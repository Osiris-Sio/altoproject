## 🎯 Objectif du Projet

Développer une application mobile permettant à deux utilisateurs d'établir une connexion sécurisée via un système de pairing par QR Code, puis d'échanger des informations chiffrées de bout en bout.

**Backend fourni :** Le serveur Spring Boot est déjà développé et disponible sur l'url https://alto.samyn.ovh. Vous devez développer l'application mobile Flutter.

## 🚀 Installation et Démarrage (Développement)

Ce guide vous aidera à configurer et à exécuter l'application Flutter en mode développement.

### Prérequis

- **Flutter SDK**: Assurez-vous d'avoir Flutter installé sur votre machine. Vous pouvez suivre les instructions officielles [ici](https://flutter.dev/docs/get-started/install).
- **Git**: Pour cloner le dépôt.
- **Un IDE**: Visual Studio Code avec l'extension Flutter ou Android Studio sont recommandés.
- **Un appareil ou émulateur**: Pour exécuter l'application (Android ou iOS).

### Étapes d'Installation

1.  **Cloner le dépôt**:

    ```bash
    git clone https://github.com/votre-utilisateur/altoproject.git
    ```

    (Remplacez `votre-utilisateur` par l'utilisateur GitHub réel du projet)

2.  **Naviguer vers le dossier du projet Flutter**:

    ```bash
    cd altoproject/src
    ```

3.  **Installer les dépendances**:

    ```bash
    flutter pub get
    ```

4.  **Exécuter l'application**:
    Assurez-vous qu'un émulateur est en cours d'exécution ou qu'un appareil physique est connecté.
    ```bash
    flutter run
    ```

### Backend

Le backend Spring Boot est hébergé et accessible à l'adresse `https://alto.samyn.ovh`. Aucune installation ou configuration locale du backend n'est nécessaire pour le développement de l'application mobile.
