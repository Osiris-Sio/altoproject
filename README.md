## 🎯 Project Objective

Develop a mobile application that allows two users to establish a secure connection via a QR code pairing system, and then exchange end-to-end encrypted information.

**Provided Backend:** The Spring Boot server is already developed and available at https://alto.samyn.ovh. You must develop the Flutter mobile application.

## 🚀 Installation and Setup (Development)

This guide will help you set up and run the Flutter application in development mode.

### Prerequisites

- **Flutter SDK**: Make sure you have Flutter installed on your machine. You can follow the official instructions [here](https://flutter.dev/docs/get-started/install).
- **Git**: To clone the repository.
- **An IDE**: Visual Studio Code with the Flutter extension or Android Studio are recommended.
- **A device or emulator**: To run the application (Android or iOS).

### Installation Steps

1.  **Clone the repository**:

    ```bash
    https://github.com/Osiris-Sio/altoproject.git
    ```

2.  **Navigate to the Flutter project directory**:

    ```bash
    cd altoproject/src
    ```

3.  **Install dependencies**:

    ```bash
    flutter pub get
    ```

4.  **Run the application**:
    Ensure an emulator is running or a physical device is connected.
    ```bash
    flutter run
    ```

### Backend

The Spring Boot backend is hosted and accessible at `https://alto.samyn.ovh`. No local backend installation or configuration is required for mobile application development.
